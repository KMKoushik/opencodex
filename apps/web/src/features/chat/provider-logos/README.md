# Provider marks

SVGs are vendored from [models.dev](https://github.com/anomalyco/models.dev/tree/7d2a55773af9dab3066581d87fb205d6ef394ac8/providers), revision `7d2a55773af9dab3066581d87fb205d6ef394ac8`, under the accompanying MIT [license](./LICENSE). `ollama.svg` comes from `providers/ollama-cloud/logo.svg`; other filenames match their provider directory.

The UI uses the SVGs as local, monochrome masks colored by the current theme. Unknown providers get a generic chip icon. No runtime logo requests leave the app.
