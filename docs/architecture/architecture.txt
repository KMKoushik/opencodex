  DEV          Vite :5173 proxies /api to :4310; desktop launches the cached macOS app.
  WEB BUILD    Node hosts the UI and gateway on loopback; native tools require a running desktop app.
  DESKTOP      Electron hosts the built UI and gateway; its separate tool endpoint also runs during development.
