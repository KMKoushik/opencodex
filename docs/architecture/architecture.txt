  RUNTIME HOSTING

  DEV          Vite :5173 proxies /api to :4310; macOS launches cached OpenCodex.app.
  WEB BUILD    Node gateway serves the UI and API on one loopback origin.
  DESKTOP      Electron main hosts the gateway and built UI on a free loopback port.
